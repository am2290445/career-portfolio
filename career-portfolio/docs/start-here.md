# Start here

You do not need to choose a career today. Use this short path to explore the work and see what skills it uses.

## 1. Pick a question

- **What openings are available?** Start with [internships, co-ops, and jobs](/opportunities/).
- **What do these jobs ask people to do?** Read the [career guide](/careers/) and [employer comparison](/careers/employer-comparison).
- **How can my studies help?** Visit [skills for AI, business, and IS](/skills/).
- **How does AI help a business?** Read [AI, business, and information systems](/research/).

## 2. Compare the work level

- **Internship:** a shorter work placement while studying.
- **Co-op:** a longer work placement, often tied to a semester or project.
- **Early-career job:** a full-time role for a new graduate or someone beginning in the field.

Read the job description to check the employer's tasks, requirements, location, and deadline. Similar titles can mean different work at different companies.

## 3. Connect a skill to evidence

Choose one skill from the [skills page](/skills/), then use the [portfolio roadmap](/portfolio-roadmap) to plan a small example. The [Portfolio Plan](/plan) shows how I will organize my evidence. A project idea is not completed work; publish it only after it is built and checked.

To see existing work, visit [Projects](/projects/) or open the [Professional Hub](/professional-hub/) for my profiles and résumé.

## 4. Follow one source

Open one employer posting from the [source log](/sources/). Find one detail in the posting, see where the site uses it, and try the check listed for that page. The [peer-review guide](/peer-review) explains how to record feedback and changes.
