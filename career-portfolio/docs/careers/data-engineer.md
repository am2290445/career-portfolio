# Data Engineer

<span class="eyebrow">CAREER FILE 03 / DATA INFRASTRUCTURE</span>

## Job overview

A Data Engineer designs, builds, tests, and maintains systems that move and prepare data for analytics, reporting, and applications. The role makes data available, consistent, secure, and dependable.

## Job description / responsibilities

- Build data pipelines that extract, transform, and load data (ETL/ELT).
- Integrate information from databases, APIs, files, and business applications.
- Design and maintain data warehouses, lakes, and data models.
- Automate workflows and monitor pipeline reliability.
- Test data quality, resolve failures, and document lineage.
- Work with analysts, scientists, developers, and governance teams.
- Apply access controls and privacy-aware engineering practices.

## Skills and tools

SQL, Python, data structures, relational databases, Git, testing, and data modeling. Depending on the employer: Spark, Kafka, Airflow, dbt, Snowflake, Databricks, BigQuery, Redshift, Azure, AWS, or Google Cloud.

## Education and preparation

Computer science, information systems, data engineering, or another technical degree can be relevant. Demonstrated programming, database design, cloud fundamentals, and reliable software practices are valuable. Requirements differ among employers.

## How it uses data analytics

Data engineering enables analytics by creating reusable, trustworthy datasets. It focuses less on interpreting business trends and more on the infrastructure and data quality that make analysis possible.

## How the role can help a business grow

- Provide timely data for faster decisions.
- Automate repetitive data preparation.
- Improve data quality and consistency across departments.
- Support larger datasets, new products, and more users.
- Create a foundation for forecasting and machine learning.

**Illustrative business example:** An organization stores customer and order data in separate systems. A Data Engineer creates tested pipelines that combine them in a governed warehouse. Analysts can measure repeat purchases and service issues using consistent data, helping teams make informed retention and operations decisions.

## Portfolio project

Build a small end-to-end pipeline: collect public or synthetic data, validate it, load it into PostgreSQL, transform it with SQL, and document the architecture. Include tests, a data dictionary, and a diagram. Do not expose credentials or private data.

## Career development

Data Engineer → Senior Data Engineer → Data Platform Engineer, Data Architect, or Engineering Lead.
