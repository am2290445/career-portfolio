## Creative direction

- **Explorer:** curiosity, discovery, and learning.
- **Creator:** experimentation and making useful things.
- **Visual style:** postmodern color, expressive type, layered cards, and playful shapes, balanced with readability and accessibility.

The site explores a professional direction; it does not claim experience or results that are not supported by project evidence.

## Research and privacy

Job details were checked November 12, 2026. Openings and requirements may change, so follow the original employer link before applying. Public pages show source-based job requirements and research decisions. Personal eligibility details and the full course reflection belong in the private course submission.

## Run the site

From the career-portfolio folder, install Node.js 22.16+ or 24+, then run:

```bash
npm install
npm run docs:dev
```

To make a production build:

```bash
npm run docs:build
npm run docs:preview
```

## Publish with GitHub Pages

The workflow in .github/workflows/deploy.yml builds the VitePress site in the career-portfolio folder. The site uses the /career-portfolio/ base path in career-portfolio/docs/.vitepress/config.mts.

After changes are pushed to main, check the repository's Actions page for a successful Pages deployment. The published site is:

**https://am2290445.github.io/career-portfolio/**
